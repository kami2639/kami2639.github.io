# 漫游计划（第一章网站）

这是一个静态旅行规划网站。访客可以选择目的地、安排城市顺序和停留时间，并整理想体验的内容。

## 本地预览

在电脑上用浏览器打开 `dist/index.html`。网页样式和交互代码都在 `dist/` 文件夹；图片来自 Unsplash，字体来自 Google Fonts，显示这些在线资源需要网络。
